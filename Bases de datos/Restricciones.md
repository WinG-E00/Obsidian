Que son?
;;
Las **restricciones** (_constraints_) ==son las **reglas de oro** que le pones a tus tablas para que nadie meta información falsa, incompleta o por error==.
___
Sirven para que tu base de datos sea **confiable**. Si alguien intenta guardar algo que rompe una regla, SQL simplemente **no lo deja**.
