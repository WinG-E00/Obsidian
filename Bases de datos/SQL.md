Que es?
;;
Una base de datos SQL seria basicamente una base de datos que almacena su informacion en base a un sistema de tablas que contiene un atributo que seria su [[Fila]] y una instancia que seria [[Columna]] tambien llamada registro
Las bases de datos SQL se manipulan con este lenguaje que esta compuesto por dos partes
El lenguaje de definicion de datos [[DDL]]
y el lenguaje de manejo de datos [[DML]]
