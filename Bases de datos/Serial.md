Para que es? tipo de datos?
;;
El tipo de dato **SERIAL** se utiliza principalmente para ==crear columnas con **autoincremento**==, lo que permite que el motor de la base de datos asigne automáticamente un número entero único a cada nueva fila. Es la herramienta estándar en sistemas como PostgreSQL para definir identificadores únicos, comúnmente usados como **claves primarias** (Primary Keys).
