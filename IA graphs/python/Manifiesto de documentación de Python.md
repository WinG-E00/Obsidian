## Alcance

190 notas en español para comprender el núcleo de Python 3.14 y practicar sus relaciones. Incluye operaciones principales de tipos incorporados y una selección de biblioteca estándar; las referencias oficiales amplían las APIs. No hay archivos duplicados para un mismo concepto dentro de esta colección.

El archivo solicitado `rules/rules_for_notes_creation.md` estaba vacío al inspeccionarlo. La organización sigue el pedido de notas atómicas y la guía local `IA graphs/obsidian-atomic-study-notes/SKILL.md`, con frontmatter y wikilinks de la skill `obsidian-markdown`.
