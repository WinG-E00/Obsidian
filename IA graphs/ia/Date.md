# Date

Objeto que representa **fechas y horas** en JavaScript, calculadas en milisegundos desde el 1 de enero de 1970.

## Métodos

| Método | Descripción |
| ------ | ----------- |
| `getDate()` | Devuelve el día del mes (1–31) |
| `getFullYear()` | Devuelve el año con 4 dígitos |
| `getTime()` | Devuelve los milisegundos desde 1970 |
| `toISOString()` | Convierte la fecha al formato ISO |
| `now()` | Devuelve el momento actual en milisegundos |
| `setMonth()` | Establece el mes de la fecha |

## Propiedades

| Propiedad | Descripción |
| --------- | ----------- |
| `prototype` | Permite agregar métodos propios al objeto Date |
| `constructor` | Función usada para crear el objeto |
| `length` | Cantidad de argumentos de la función Date (`7`) |
