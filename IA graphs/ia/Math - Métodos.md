# Métodos de Math

Cada método es una **función estática** del objeto [[ia/Math]].

| Método | Descripción |
| ------ | ----------- |
| [[max]] | Devuelve el número más grande |
| [[min]] | Devuelve el número más pequeño |
| [[random]] | Número aleatorio entre 0 y 1 |
| [[round]] | Redondea al entero más cercano |
| [[floor]] | Redondea hacia abajo |
| [[sqrt]] | Calcula la raíz cuadrada |
