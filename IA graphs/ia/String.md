# String

Objeto que representa una **cadena de texto** y ofrece herramientas para manipularla.

## Métodos

| Método | Descripción |
| ------ | ----------- |
| `toUpperCase()` | Convierte todo el texto a mayúsculas |
| `toLowerCase()` | Convierte todo el texto a minúsculas |
| `slice()` | Extrae una parte del texto |
| `split()` | Divide el texto en un array según un separador |
| `replace()` | Reemplaza una parte del texto por otra |
| `includes()` | Verifica si el texto contiene una subcadena |

> También existen: `trim()`, `charAt()`, `indexOf()`, `concat()`.

## Propiedades

| Propiedad | Descripción |
| --------- | ----------- |
| `length` | Cantidad de caracteres del texto |
| `constructor` | Referencia a la función que creó el objeto |
| `prototype` | Permite agregar métodos propios al objeto String |
