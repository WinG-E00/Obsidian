# Métodos de String

Cada método es una **acción** que puede realizar el objeto [[ia/String]].

| Método | Descripción |
| ------ | ----------- |
| [[toUpperCase]] | Convierte a mayúsculas |
| [[toLowerCase]] | Convierte a minúsculas |
| [[slice]] | Extrae una parte del texto |
| [[split]] | Divide el texto en un array |
| [[replace]] | Reemplaza parte del texto |
| [[includes]] | Verifica si contiene una subcadena |
