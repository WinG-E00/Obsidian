# Array

Objeto que representa una **lista ordenada** de elementos. Es uno de los más usados en JavaScript.

## Métodos

| Método | Descripción |
| ------ | ----------- |
| `push()` | Agrega uno o más elementos al final del array |
| `map()` | Crea un nuevo array aplicando una función a cada elemento |
| `filter()` | Crea un nuevo array solo con los elementos que cumplen una condición |
| `reduce()` | Reduce el array a un único valor acumulado |
| `sort()` | Ordena los elementos del array |
| `find()` | Devuelve el primer elemento que cumple una condición |

## Propiedades

| Propiedad | Descripción |
| --------- | ----------- |
| `length` | Cantidad de elementos que contiene el array |
| `index` | Posición de cada elemento (empieza en `0`) |
| `prototype` | Permite agregar métodos propios al objeto Array |
