# Métodos de Object

Cada método es una **acción** que puede realizar el objeto [[ia/Object]].

| Método | Descripción |
| ------ | ----------- |
| [[keys]] | Devuelve las claves como array |
| [[values]] | Devuelve los valores como array |
| [[assign]] | Copia propiedades entre objetos |
| [[entries]] | Devuelve los pares clave-valor |
| [[hasOwnProperty]] | Verifica si existe una propiedad propia |
| [[create]] | Crea un objeto con un prototipo dado |
