# Math

Objeto con **constantes y funciones matemáticas**. No puede ser instanciado con `new`, sus métodos y propiedades son estáticos.

## Métodos

| Método | Descripción |
| ------ | ----------- |
| `max()` | Devuelve el número más grande de una lista |
| `min()` | Devuelve el número más pequeño de una lista |
| `random()` | Devuelve un número aleatorio entre `0` y `1` |
| `round()` | Redondea un número al entero más cercano |
| `floor()` | Redondea un número hacia abajo |
| `sqrt()` | Calcula la raíz cuadrada |

## Propiedades

| Propiedad | Descripción |
| --------- | ----------- |
| `PI` | Valor de $\pi$ (`3.14159...`) |
| `E` | Número de Euler (`2.718...`) |
| `SQRT2` | Raíz cuadrada de 2 (aprox. `1.414`) |
