# Métodos de Date

Cada método es una **acción** que puede realizar el objeto [[ia/Date]].

| Método | Descripción |
| ------ | ----------- |
| [[getDate]] | Devuelve el día del mes |
| [[getFullYear]] | Devuelve el año con 4 dígitos |
| [[getTime]] | Devuelve los milisegundos desde 1970 |
| [[toISOString]] | Convierte al formato ISO |
| [[now]] | Momento actual en milisegundos |
| [[setMonth]] | Establece el mes |
