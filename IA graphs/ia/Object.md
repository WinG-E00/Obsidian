# Object

Objeto que representa la **base de todos los objetos** en JavaScript. Casi todo en JS es un objeto o hereda de `Object`.

## Métodos

| Método | Descripción |
| ------ | ----------- |
| `keys()` | Devuelve un array con las claves de un objeto |
| `values()` | Devuelve un array con los valores de un objeto |
| `assign()` | Copia propiedades de un objeto a otro |
| `entries()` | Devuelve los pares clave-valor como arrays |
| `hasOwnProperty()` | Verifica si el objeto tiene una propiedad propia |
| `create()` | Crea un objeto con un prototipo definido |

## Propiedades

| Propiedad | Descripción |
| --------- | ----------- |
| `prototype` | Base para la herencia entre objetos |
| `constructor` | Función usada para crear el objeto |
| `__proto__` | Referencia al prototipo del objeto |
