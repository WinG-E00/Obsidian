# Métodos de Array

Cada método es una **acción** que puede realizar el objeto [[ia/Array]].

| Método | Descripción |
| ------ | ----------- |
| [[push]] | Agrega elementos al final del array |
| [[map]] | Crea un nuevo array aplicando una función a cada elemento |
| [[filter]] | Filtra elementos según una condición |
| [[reduce]] | Reduce el array a un único valor |
| [[sort]] | Ordena los elementos |
| [[find]] | Busca el primer elemento que cumple una condición |
| [[slice]] | Extrae una copia de una parte del array |
