# length

Propiedad de [[ia/Array - Propiedades]] que indica la **cantidad de elementos** de un array, y de [[ia/String - Propiedades]] que indica la **cantidad de caracteres** del texto.

En [[ia/Date - Propiedades]] representa la cantidad de argumentos esperados por la función `Date` (7).

```js
const numeros = [1, 2, 3];
numeros.length; // 3

"hola".length; // 4
```
