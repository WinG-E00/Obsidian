Que es el data manipulation lenguaje?
;;
El lenguaje **DML** (_Data Manipulation Language_ o Lenguaje de Manipulación de Datos) es la parte de SQL que se encarga de lo más divertido y frecuente: **interactuar o modificar  los datos** que ya están dentro de las tablas.
