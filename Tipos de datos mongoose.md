# Tipos de datos en Mongoose

- **Texto:** `String`.
- **Números:** `Number`, `Decimal128`, `Double`, `Int32`, `BigInt`.
- **Lógicos:** `Boolean`.
- **Fechas:** `Date`.
- **Identificadores:** `ObjectId`, `UUID`.
- **Binarios:** `Buffer`.
- **Colecciones:** `Array`, `Map`.
- **Estructuras complejas:** `Schema` (subdocumentos), `Mixed`, `Union`.
