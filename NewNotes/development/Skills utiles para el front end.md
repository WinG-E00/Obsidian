

## Skills Esenciales de Frontend para Vite, React y TypeScript

### 1. La Skill Destacada: `frontend-design`

- **Enfoque principal:** Especializada en diseñar interfaces de usuario utilizando la pila de **React, TypeScript, Vite y Tailwind CSS**.
    
- **Por qué destaca:** Su objetivo principal es romper con los diseños genéricos típicos de la IA. Guía el proceso creativo estableciendo directrices estéticas claras (tipografía, jerarquía visual, paletas de colores y espaciados) antes de escribir código.
    

### 2. Arquitectura y Componentes (`react-vite-expert`)

- **Enfoque principal:** Estructuración de proyectos escalables y automatización de componentes.
    
- **Por qué destaca:** Permite generar rápidamente componentes limpios con tipado estricto, hooks personalizados y configuraciones óptimas para Vite, asegurando que el código visual mantenga un estándar profesional.
    

### 3. Sistemas de Diseño y Animación

- **shadcn/ui & Tailwind v4 Skills:** Indispensables para incorporar componentes interactivos con un acabado visual prémium, minimalista y de alta gama.
    
- **Framer Motion / Three.js Skills:** Recomendadas si buscas añadir animaciones fluidas, transiciones sofisticadas o efectos visuales interactivos que hagan que la aplicación destaque visualmente.
