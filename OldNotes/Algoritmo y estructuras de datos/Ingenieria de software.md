## Computadora como sistema


**Elementos**
Los elementos de una computadora son
Procesador, placa madre, memorias ram, fuente de poder, teclado, mouse, pantalla, Software(Sistema operativo)


**Interacciones**
Las interacciones físicas dentro de una computadora ocurren mediante la transmisión de señales eléctricas a alta velocidad a través de los buses de datos en la placa madre, conectando eléctricamente a la CPU con la memoria RAM, los dispositivos de almacenamiento y el resto del hardware. A nivel lógico y operativo, el software de sistema y los controladores (drivers) median entre los programas de aplicación y los componentes físicos, traduciendo instrucciones de código en estímulos eléctricos para que el hardware ejecute operaciones aritméticas y lógicas. Asimismo, se produce una interacción bidireccional y continua entre el usuario y el sistema a través de los periféricos de entrada y salida, donde los comandos introducidos actúan como estímulos que el sistema procesa para devolver una respuesta tangible en pantalla o mediante otros dispositivos.


**Objetivo en comun**
El objetivo común de la computadora es procesar datos de manera rápida, eficiente y precisa para transformarlos en información útil, respondiendo directamente al propósito de diseño para el cual fue construida por el ser humano.

# Rigidos
El sistema solar:
El sistema solar es un sistema solar por que tiene un comportamiento determinado, no incluye ningun factor humano o psicologico, es un sistema que simplemente es por si solo, es un sistema que solo esta ahi para cumplir una funcion, respetar las leyes fisicas.

**Computadora**
Una computadora es un sistema rigido ya que este responde a un comportamiento determinado,**:** Su estructura física (el hardware), su circuitería, la arquitectura del procesador y las reglas de la lógica binaria son totalmente deterministas. Si le das una instrucción matemática exacta a la CPU, el resultado siempre será el mismo; si un cable se rompe o un componente falla, el sistema no tiene la capacidad de "improvisar" una solución por sí mismo, sino que se bloquea o colapsa. No hay ambigüedad ni adaptación autónoma en su funcionamiento base.
Lo unico capas de dar flexibiliadad a este sistema es la creacion de patrones binarios que se crean para cumplir un proposito en especifico.
