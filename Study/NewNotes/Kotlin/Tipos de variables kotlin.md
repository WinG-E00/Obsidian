- **`val` (Value):** Variable de **solo lectura** (inmutable). Se le asigna un valor una sola vez y **no se puede reasignar** jamás. Es como una constante local.
    
- **`var` (Variable):** Variable de **lectura y escritura** (mutable). Su valor **sí puede cambiar** y reasignarse las veces que necesites a lo largo del programa.

```kotlin
//Para asignar variables se puede hacerde la siguiente forma
val variableedEntorno: String = "hola xd";

//Para variables globales 
var variableGlobal: String = "safaff";
```
