# `authenticate`

Comprueba que Sequelize puede conectarse a la base de datos.

## Sintaxis

```js
sequelize.authenticate()
```

```js
await sequelize.authenticate();
```

Resuelve si la conexión funciona y lanza un error si no puede autenticarse.
