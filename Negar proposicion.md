Como se niega la preposicion?

| **Original** | **Negación** | **Significado**                   |
| ------------ | ------------ | --------------------------------- |
| $=$          | $\neq$       | Igual $\rightarrow$ Diferente     |
| $\neq$       | $=$          | Diferente $\rightarrow$ Igual     |
| $>$          | $\leq$       | Mayor $\rightarrow$ Menor o igual |
| $<$          | $\geq$       | Menor $\rightarrow$ Mayor o igual |
| $\geq$       | $<$          | Mayor o igual $\rightarrow$ Menor |
| $\leq$       | $>$          | Menor o igual $\rightarrow$ Mayor |
